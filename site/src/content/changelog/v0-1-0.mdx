### New

- Shared inboxes with forwarding, IMAP and SMTP, Google and Microsoft 365 mailboxes.
- Tickets with statuses, priorities, assignees, teams, tags, snoozing, merging and bulk actions.
- Internal notes with mentions, saved replies and personal or shared views.
- Live chat widget in 13 languages, with identity verification.
- AI: reply drafts, rewriting, summaries, copilot, auto-triage, translation, semantic search and a widget answer bot.
- Free and Pro plans with pooled AI credits on opendesk Cloud.
- Knowledge base with collections and a public help center.
- Automations on ticket created, customer replied, agent replied and ticket updated.
- SLA policies with first-reply and resolution targets per priority.
- Overview report and CSAT surveys.
- Public REST API with scoped API keys, idempotency keys and an OpenAPI 3.1 spec.
- Signed webhooks with delivery history.
- Realtime updates, presence and typing, with missed-event replay.
- Sign-in with passwords, two-factor, Google, Microsoft, GitHub or OIDC.
- One-command self-hosting with Docker and Caddy.
