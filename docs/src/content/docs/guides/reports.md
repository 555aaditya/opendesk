title: Reports

---

The reports page shows how your support is going for a date range you choose.

## Metrics

| metric | meaning |
| --- | --- |
| Created | Tickets created in the range. |
| Solved | Tickets solved in the range. |
| Open now | Tickets open at this moment. |
| First response (median) | Median minutes from a ticket's creation to the first agent reply. |
| Resolution (median) | Median minutes from creation to solved. |
| CSAT | Average satisfaction score and the number of ratings. See [CSAT](/guides/csat/). |
| SLA breached | Tickets that missed an [SLA](/guides/sla-policies/) target. |

## Breakdowns

- **By day:** created and solved, as a chart.
- **By channel:** email, chat, API and portal.
- **By agent:** tickets solved and median first response time per member.

Medians are used rather than averages so one very slow ticket does not hide how the team usually performs.
