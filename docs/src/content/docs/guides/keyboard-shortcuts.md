---
title: Keyboard shortcuts
description: Most things in opendesk work without a mouse.
---

Press <kbd>?</kbd> anywhere in the app to see this list. <kbd>mod</kbd> is <kbd>⌘</kbd> on macOS and <kbd>Ctrl</kbd> elsewhere.

## General

| keys | action |
| --- | --- |
| <kbd>mod</kbd> <kbd>k</kbd> | Command menu |
| <kbd>/</kbd> | Search tickets |
| <kbd>c</kbd> | New ticket |
| <kbd>?</kbd> | Keyboard shortcuts |
| <kbd>g</kbd> then <kbd>i</kbd> | Go to inbox |
| <kbd>g</kbd> then <kbd>c</kbd> | Go to contacts |
| <kbd>g</kbd> then <kbd>k</kbd> | Go to knowledge base |
| <kbd>g</kbd> then <kbd>s</kbd> | Go to settings |

## Ticket list

| keys | action |
| --- | --- |
| <kbd>j</kbd> | Next ticket |
| <kbd>k</kbd> | Previous ticket |
| <kbd>enter</kbd> | Open ticket |
| <kbd>x</kbd> | Select ticket |
| <kbd>esc</kbd> | Close ticket or clear selection |

## Ticket

| keys | action |
| --- | --- |
| <kbd>r</kbd> | Reply |
| <kbd>n</kbd> | Add a note |
| <kbd>a</kbd> | Assign |
| <kbd>e</kbd> | Solve |
| <kbd>mod</kbd> <kbd>enter</kbd> | Send |
