## Saved replies

A **saved reply** is a reusable answer with a title, an optional shortcut and a formatted body. Insert one while writing a reply or note, then edit it before sending. Saved replies are shared with the whole workspace.

Good saved replies are short, start with the answer, and link to a [help article](/guides/knowledge-base/) for detail.

## Views

A **view** is a saved set of ticket filters. It appears in the inbox sidebar with a live count.

Views can filter by:

- status, priority and severity (one or more of each; severity can include "none")
- assignee: `me`, unassigned, or a specific member
- team, mailbox, tag and channel
- a text query

A view is **personal** or **shared** with the workspace. Shared views are ordered by position, so the team sees the same queues in the same order. New workspaces start with default views.
